An entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun.

## The joke

> My dad says working the elevator has its ups and downs, but he loves lifting people's spirits.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes one
original dad joke to `/output/entry.txt`. Before writing, its `gate_check`
function enforces the competition gate: the text must be UTF-8, 1 to 200
characters, not only whitespace, and a single line.

Run it:

```sh
python3 main.py
```
